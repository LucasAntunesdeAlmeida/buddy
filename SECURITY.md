# Security

Please report a vulnerability privately, through **Report a vulnerability** on this repository's [Security tab](https://github.com/LucasAntunesdeAlmeida/buddy/security), not in a public issue.

Buddy is a spare-time project, so there's no promised response time, and only the latest release gets fixes.

Worth reporting: anything that breaks what the [README's Privacy section](README.md#privacy) promises, such as Buddy storing window titles or connecting to the network, and any way a file or input could make him run code.
